# Be Vietnam Pro

Self-hosted WOFF2 assets from the official Google Fonts CSS API, downloaded
2026-10-13. Normal weights: 400, 500, 600, 700. Italic weights: 400, 700.
Each includes Vietnamese, Latin Extended and Latin subsets with unicode ranges.
The browser loads only the subsets/styles used by the page; font-display is swap.

Source: https://fonts.google.com/specimen/Be+Vietnam+Pro
Authors: https://github.com/bettergui/BeVietnamPro
License: be-vietnam-pro-OFL.txt (SIL Open Font License 1.1).

The same font files and stylesheet are mirrored under the console public assets
so both applications work independently. Earlier Google Sans Flex assets are
retained for compatibility but are no longer declared by the active stylesheet.

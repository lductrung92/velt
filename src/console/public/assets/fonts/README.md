# Be Vietnam Pro

Self-hosted mirror of the site font assets. Normal weights: 400, 500, 600, 700;
italic weights: 400, 700. Each has Vietnamese, Latin Extended and Latin subsets.
The stylesheet uses font-display: swap and contains only local WOFF2 URLs.
